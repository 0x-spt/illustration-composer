# Prompt samples

Журнал реальных ответов `/api/compose-intent` (Claude Haiku 5.5) на метафоры. Нужен, чтобы
оценить качество системного промпта и ловить регрессии при его правке.

Заполняется вручную после запуска `npx vercel dev` с настоящим `ANTHROPIC_API_KEY`:

```
curl -X POST localhost:3000/api/compose-intent -d '{"text":"Финансовая подушка безопасности"}'
```

Записать 5 метафор: текст, `source`, предметы (hero / support / backdrop), оценка осмысленности.
