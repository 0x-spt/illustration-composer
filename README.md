# Композитор иллюстраций

Собирает иллюстрации из библиотеки предметов Chulakov. Пишешь идею («копим на мечту») или просто перечисляешь предметы, сервис подбирает и раскладывает их. Дальше можно поправить сцену руками, сменить палитру и скачать SVG, который нормально открывается в Figma.

Предметы не генерируются и не перерисовываются: в сцену попадают исходные векторы из Figma как есть.

![демо](docs/media/demo.gif)

## Что умеет

- По фразе подбирает 2–3 предмета (Claude Haiku). Если ключа нет или API недоступен, подбирает сам по каталогу смыслов.
- По списку предметов собирает сцену без AI, понимает опечатки и синонимы.
- Редактор: перемещение, поворот, отражение, дубль, слои, главное/фоновое состояние, undo/redo.
- Форматы 1000×1000, 1200×630, 800×1200 или свой. Детализация L и S.
- Три палитры из Figma и своя (JSON, список hex, .ase).
- Экспорт в SVG: исходные пути, итоговые hex, каждый предмет отдельной группой.

## Как устроено

- `packages/library` — библиотека, выгруженная из Figma: SVG предметов и декора, `manifest.json` с размерами, палитры, шаблоны раскладок из примеров дизайнера. Цвета в SVG размечены по местам палитры, поэтому перекраска — это подстановка цвета, а не правка путей.
- `packages/core` — логика без React: сцена, раскладка, перекраска, экспорт.
- `apps/web` — редактор на React.
- `server` — функция подбора предметов через Claude, собирается в `api/compose-intent.js` для Vercel.
- `scripts/library-sync` — выгрузка из Figma и сборка примеров.

Подробнее про хранение и переиспользование SVG, раскладку и принятые решения — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Запуск

Нужен Node.js 24.

```bash
npm i
cp .env.example .env      # ANTHROPIC_API_KEY, без него работает офлайн-подбор
npm run dev -w @ic/web    # http://localhost:5173
```

Подбор через Claude локально работает только через `npx vercel dev`, обычный `vite dev` серверную функцию не поднимает.

```bash
npm test                  # юнит-тесты
npm run test:e2e          # e2e (перед первым запуском: npx playwright install chromium)
npm run examples          # пересобрать examples/
npm run library:sync      # заново выгрузить библиотеку из Figma (FIGMA_TOKEN)
```

## AI-инструменты

- Claude Code (Claude Opus 5.5) — при разработке.
- Claude Haiku 5.5 — внутри сервиса, подбирает предметы по фразе.
